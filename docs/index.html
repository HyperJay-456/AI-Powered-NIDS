🤖 Exactly Three Authorized Algorithms

By architectural mandate, classification is restricted strictly to three complementary algorithmic paradigms. No fourth algorithm, ad-hoc voting ensembles, or external cloud inference endpoints are permitted.

📐

Support Vector Machine (LinearSVC)

Constructs optimal maximum-margin separating hyperplanes in standardized continuous feature spaces using dual coordinate descent formulation. Well-suited for high-dimensional boundary isolation between benign baselines and volumetric flooding.

LinearSVC StandardScaler CSR Sparse Matrix Balanced Class Weights
🧠

Multilayer Perceptron (MLPClassifier)

Feedforward artificial neural network with adaptive mini-batch iteration (partial_fit), Adam stochastic optimization, and genuine training-loss convergence stopping. Discovers complex non-linear interactions across subtle temporal features.

MLPClassifier Adaptive Learning Rate Convergence Semantics Early Stopping
🌲

Decision Tree (CART Classifier)

Interpretable, deterministic recursive binary splitting on raw physical flow attributes (packet lengths, inter-arrival times, port categories) utilizing Gini impurity criteria. Delivers transparent rule paths for forensic verification.

⚡ Installation & Windows Launch Scripts

Get started in seconds using the native one-click Windows launch utilities or standard PowerShell commands.

🚀

One-Click Launch Scripts

Native Windows batch files configured for rapid workstation execution:

  • start.bat: Verifies .venv, checks port 8501, boots Streamlit server in a dedicated window, and launches your browser.
  • stop.bat: Detects and terminates the active NIDS server process tree on port 8501 cleanly.
# Simply double-click in Windows Explorer:
start.bat  <-- Launch NIDS
stop.bat   <-- Shutdown NIDS
💻

Manual PowerShell Setup

For terminal operators and Python environment customization:

# 1. Clone & enter repository
git clone https://github.com/HyperJay-456/AI-Powered-NIDS.git
cd AI-Powered-NIDS

# 2. Initialize virtual environment
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. Install dependencies & run
pip install -r requirements.txt
streamlit run app.py
